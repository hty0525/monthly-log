# 작업 완료 품질 체크리스트

**모든 코딩 작업을 완료한 후, 완료 표시 전에 이 체크리스트를 실행하세요.**

## 🔍 재사용성 체크

### 코드 중복
- [ ] 코드를 복사-붙여넣기 했는가? 그렇다면 공통 위치로 추출
- [ ] 2개 이상의 비슷한 함수/컴포넌트가 있는가? 그렇다면 하나로 일반화
- [ ] 여러 곳에서 사용되는 하드코딩 값이 있는가? 그렇다면 상수로 추출

### 컴포넌트 재사용성
- [ ] 이 컴포넌트를 다른 곳에서 사용할 수 있는가? 그렇다면 충분히 일반적인가?
- [ ] 이 컴포넌트에 커스터마이징을 위한 props가 있는가?
- [ ] 이 컴포넌트가 올바른 위치(`shared/` vs 기능별)에 있는가?

### 훅 재사용성
- [ ] 이 로직이 여러 컴포넌트에서 사용되는가? 그렇다면 커스텀 훅으로 추출
- [ ] 이 훅을 다른 사용 사례에도 일반화할 수 있는가?
- [ ] 이 훅의 이름이 적절하고 문서화되어 있는가?

### 유틸리티 함수
- [ ] 반복되는 계산/변환이 있는가? 그렇다면 유틸리티 생성
- [ ] 유틸리티 함수가 `shared/utils/`에 있는가, 아니면 컴포넌트에 묻혀있는가?
- [ ] 이 유틸리티를 앱 전체에서 사용할 수 있는가?

## ⚡ 효율성 체크

### 성능
- [ ] 불필요한 리렌더링이 있는가? `useMemo`, `useCallback`, `memo` 고려
- [ ] 비용이 큰 계산이 메모이제이션되어 있는가?
- [ ] 큰 컴포넌트가 지연 로딩되어 있는가?
- [ ] 리스트에 적절한 key가 있는가?

### 번들 크기
- [ ] 하나의 함수만 필요한데 전체 라이브러리를 import 했는가?
- [ ] 무거운 의존성이 지연 로딩되어 있는가?
- [ ] 사용하지 않는 import가 제거되었는가?

### API 효율성
- [ ] 중복된 API 호출을 하고 있는가?
- [ ] 데이터가 적절히 캐시되어 있는가?
- [ ] 가능한 경우 API 호출이 배치 처리되어 있는가?

### 코드 효율성
- [ ] 가장 효율적인 알고리즘/자료구조를 사용하고 있는가?
- [ ] 불필요한 루프나 반복이 있는가?
- [ ] 내장 메서드로 단순화할 수 있는가?

## 🧹 코드 품질

### 단순성
- [ ] 이것이 작동하는 가장 단순한 해결책인가?
- [ ] 다른 개발자가 30초 안에 이해할 수 있는가?
- [ ] 과도한 엔지니어링을 피했는가?

### 네이밍
- [ ] 변수/함수 이름이 명확하고 설명적인가?
- [ ] 이름이 프로젝트 컨벤션을 따르는가?
- [ ] 코드에 익숙하지 않은 사람도 이름을 이해할 수 있는가?

### 파일 구조
- [ ] 파일이 올바른 디렉토리에 있는가?
- [ ] 파일 구조가 논리적인가?
- [ ] 관련 파일들이 함께 그룹화되어 있는가?

## 🗑️ 정리

### 사용하지 않는 코드
- [ ] 주석 처리된 코드를 제거했는가?
- [ ] 사용하지 않는 import가 있는가?
- [ ] 사용하지 않는 변수/함수가 있는가?
- [ ] console.log와 디버그 코드를 제거했는가?

### 파일
- [ ] 중복된 파일이 있는가?
- [ ] 사용하지 않는 파일이 있는가?
- [ ] 예시/템플릿 파일이 필요한가?

## 📝 문서화

### 코드 주석
- [ ] 복잡한 로직 블록에 주석이 있는가?
- [ ] 엣지 케이스가 문서화되어 있는가?
- [ ] 명백하거나 중복된 주석을 제거했는가?

### 타입 안전성
- [ ] 모든 타입이 적절히 정의되어 있는가?
- [ ] 구체적이어야 하는데 `any` 타입이 있는가?
- [ ] 공통 타입이 올바른 위치에 있는가?

## 🎯 최종 질문

작업을 완료로 표시하기 전에 솔직하게 답변하기:

1. **재사용성**: 내일 비슷한 기능이 필요하면 이 코드를 재사용할 수 있는가?
2. **효율성**: 이 코드가 성능이 좋고 리소스 효율적인가?
3. **단순성**: 이것이 문제를 해결하는 가장 단순한 방법인가?
4. **유지보수성**: 다른 개발자가 쉽게 이해하고 수정할 수 있는가?
5. **깔끔함**: 코드베이스를 발견했을 때보다 더 나은 상태로 남겼는가?

## 🚨 위험 신호

다음 중 하나라도 "예"라면 완료 전에 리팩토링:

- [ ] 다른 파일에서 코드를 복사-붙여넣기 했다
- [ ] 이 컴포넌트/함수가 100줄이 넘는다
- [ ] 변경될 수 있는 값을 하드코딩했다
- [ ] 기존 파일과 매우 유사한 새 파일을 만들었다
- [ ] 이 코드가 어디에 있어야 할지 확실하지 않다
- [ ] TODO나 주석 처리된 코드를 남겼다
- [ ] "혹시 몰라서" 불필요한 추상화를 만들었다

## ✅ 완료 기준

다음 조건을 모두 만족할 때만 작업을 완료로 표시:
- ✅ 해당되는 모든 체크리스트 항목이 체크됨
- ✅ 위험 신호가 남아있지 않음
- ✅ 코드가 프로젝트 컨벤션을 따름
- ✅ 다른 개발자가 리뷰해도 자신 있음
